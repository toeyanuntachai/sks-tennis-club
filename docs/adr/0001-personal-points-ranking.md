# จัดอันดับรายคนด้วยแต้มสะสมรายเดือน

กลุ่ม SKS เล่นคู่ สลับคู่บ่อย และต้องการอันดับเพื่อความสนุก จึงให้ผู้เล่นแต่ละคนสะสมแต้มชนะ 3 เสมอ 1 แพ้ 0 เท่ากับคู่หู และจัดอันดับใหม่ทุกเดือนโดยเก็บประวัติเดือนเก่า ผู้ใช้ยืนยันแต้มรายคนในแชต “วางแผนเว็บกลุ่มเทนนิส” และยืนยันรอบรายเดือนเมื่อ 6 ตุลาคม 2026

เลือกแต้มสะสมแทนระบบวัดฝีมือที่ปรับตามคู่หูและคู่แข่ง เพราะกติกาเข้าใจง่ายและให้รางวัลกับการมาเล่นด้วย คนมาบ่อยอาจมีอันดับสูงกว่าคนฝีมือดีกว่าที่เล่นน้อย จึงแสดงจำนวนแมตช์ ชนะ–เสมอ–แพ้ และเปอร์เซ็นต์ชนะประกอบ ไม่ใช้สถิติเหล่านี้ตัดสินเมื่อแต้มเท่ากัน การเปลี่ยนสูตรภายหลังมีผลต่อความหมายของอันดับและประวัติแต้มที่สมาชิกใช้เปรียบเทียบกัน
