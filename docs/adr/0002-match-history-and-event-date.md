# แยกผลแมตช์จากการยกเลิกนัดและล็อกวันเมื่อมีผล

อันดับรายเดือนยึดวันของนัดตามเวลาไทย ผู้ใช้ยืนยันเมื่อ 6 ตุลาคม 2026 ว่าการยกเลิกนัดต้องเก็บผลที่เล่นจริงไว้ และล็อกวันนัดเมื่อมีผลแล้ว เพื่อไม่ให้แต้มย้ายเดือนโดยไม่ตั้งใจ ผู้กรอกและผู้เปิดนัดแก้หรือยกเลิกผลเดิมได้ รวมผลเดือนเก่า แล้วคำนวณอันดับจากผลที่ยังนับอยู่

เลือกให้ยกเลิกผลแยกจากยกเลิกนัด แทนการล้างผลทั้งหมดตามสถานะนัด เพราะการเปลี่ยนแผนของนัดไม่ได้แปลว่าแมตช์ที่เล่นแล้วไม่เกิดขึ้น การล็อกวันลดความยืดหยุ่นในการแก้วันนัด แต่ช่วยรักษาความหมายของประวัติอันดับ โดยไม่ต้องเพิ่มวันเล่นที่แยกต่างหากสำหรับทุกแมตช์
